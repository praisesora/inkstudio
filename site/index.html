Architecture

Built for actual drawing workflows

Zero cloud lock-in · Local scratch disk
WebGL

Brush & Ink Engine

Pressure, tilt, velocity, taper, dual brush tips, paper textures, wet edges, color mixing, and custom pressure curves. Imports Clip Studio Paint .sut and native .inkb presets.

17 Blends

Sparse-Tile & Vector Layers

Raster tiles, editable vector strokes (pinch, width, simplify), clipping & layer masks, layer styles, Curves/Levels/Gradient Map adjustments, CMYK soft proofing, and 1-bit Monochrome mode.

Manga / Webtoon

Panels, Tones & Perspective

Frame border folders with panel splitting, parametric speech balloons, vertical typography, screentones, effect lines, 1/2/3-point perspective rulers with brush snapping, and 9:16 Webtoon slice export.

Three.js

3D Reference & LT Baking

Embedded 3D viewport with posable IK mannequin, pose presets, .glb/.gltf/.obj import, adjustable lights, camera-to-perspective-ruler sync, and line-and-tone (LT) extraction.

Cel + Time-lapse

Animation & Time-lapse

Frame-by-frame cel animation timeline with onion skinning and stroke-based time-lapse recorder. Export directly to GIF, APNG, WebM, H.264 MP4, or PNG sequence archives.

Rust Axum WS

Real-Time Multiplayer

Self-hosted Rust WebSocket server for up to 16 peers over LAN or public invite links via Cloudflare Tunnel. Live cursors, tile-level sync, layer reservation, and zero relay servers.
